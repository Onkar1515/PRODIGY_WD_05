# 🌐 Social Media Platform

A simple Social Media Platform web application where users can create posts, like posts, and comment on posts. This project focuses on building an interactive user interface using front-end web technologies.

---

## 🚀 Features

- ✅ User profile name input
- ✅ Create and share posts
- ✅ Like posts with live counter
- ✅ Comment on posts
- ✅ Responsive and simple UI
- ✅ Dynamic content using JavaScript

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

---

## 📂 Project Structure

```

social_media_platform
│
├── index.html       # Main UI structure
├── style.css        # Styling and layout
├── script.js        # Post, Like, Comment logic

````

## ▶️ How To Use

1. Enter your username
2. Write a post
3. Click **Post**
4. Like posts using the **Like** button
5. Add comments using the comment box

---

## 🧠 How It Works

* Posts are created dynamically using JavaScript.
* Like button increases like counter.
* Comments are added under each post.
* All data is stored temporarily in browser memory.

---

## ⚠ Limitations

* Posts are not saved permanently
* No login or authentication system
* No backend or database integration
